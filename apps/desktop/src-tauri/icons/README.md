# Icons

Generated by `npm run tauri icon ../../app-icon.png` (run from `apps/desktop`).

- `app-icon.png` (repo: `apps/desktop/app-icon.png`) is the 1024×1024 source.
- This directory holds the generated desktop set: `32x32.png`, `64x64.png`,
  `128x128.png`, `128x128@2x.png`, `icon.png`, `icon.ico`, `icon.icns`, and the
  Windows Store `Square*`/`StoreLogo` assets.
- Mobile (iOS/Android) assets are intentionally **not** committed; regenerate the
  full set with `npm run tauri icon ../../app-icon.png` when M6 (mobile) starts.
- `src-tauri/tauri.conf.json` → `bundle.icon` lists the desktop set.

> **Placeholder art.** The current icon is a programmatic placeholder (dark
> gradient + gold disc + "K"). Replace it with a real designed icon before any
> release, then re-run `npm run tauri icon`.
